# GoldenAura 960 - Luxury E-Commerce Web App

GoldenAura 960 ek Django-based full-stack e-commerce project hai jisme luxury products, seamless user experience aur custom order management logic implement kiya gaya hai.

## 🌟 Main Features

* **User System:** Account registration, login, profile management aur order history.
* **Shopping & Wishlist:** Dynamic product listing, cart items management aur wishlist toggle.
* **Payments:** Integrated Razorpay checkout (Test Mode) for placing orders.
* **Luxury Invoices:** Custom styled invoice layout for both store admins and customers.
* **24-Hour Return Rule:** Backend view logic jo delivery ke 24 ghante ke andar hi return request allow karta hai.
* **Admin Controls:** Product inventory, orders aur user return requests ko manage karne ke liye tailored admin dashboard.

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite3
* **Tools:** Visual Studio Code, Git & GitHub
